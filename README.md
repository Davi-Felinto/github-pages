# github-pages
Atividade faculdade para conhecer a ferramenta github pages

 Atividade Faculdade - GitHub Pages
Este repositório foi criado como parte de uma atividade acadêmica para explorar e aprender a utilizar o GitHub Pages.
O objetivo é compreender como hospedar páginas estáticas diretamente a partir de um repositório no GitHub.

 Estrutura do Repositório
Códigos HTML/CSS: Arquivos simples para testar a publicação.

Configuração Pages: Ajustes necessários para ativar o GitHub Pages.

Documentação: Links e materiais de apoio.

 Objetivo da Atividade
Aprender GitHub como ferramenta de versionamento.

Publicar páginas estáticas de forma prática.

Explorar recursos como personalização de sites e integração com projetos.

 Tecnologias Utilizadas
HTML e CSS básicos.

GitHub Pages para hospedagem.
